# Triage labels

The repository uses the standard five Matt Pocock workflow states.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | More evidence or reporter detail is required |
| `ready-for-agent` | `ready-for-agent` | Scope and acceptance criteria are executable |
| `ready-for-human` | `ready-for-human` | A human judgment or physical action is required |
| `wontfix` | `wontfix` | The issue will not be actioned |

Each triaged issue should carry exactly one state label from this table and one
type label such as `bug` or `enhancement`.
